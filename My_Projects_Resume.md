# PROJECTS

## Multimodal RAG System for PDF Understanding (Text + Images)

**Technologies:** Python, LangChain, OpenAI GPT-4 Vision, CLIP, FAISS, PyMuPDF, Hugging Face Transformers, PyTorch, NumPy

* Designed and developed an end-to-end Multimodal Retrieval-Augmented Generation (RAG) system for processing PDF documents containing both text and images.
* Extracted textual and visual content from PDFs using PyMuPDF and generated unified embeddings using OpenAI CLIP.
* Implemented intelligent document chunking using RecursiveCharacterTextSplitter to improve retrieval accuracy and contextual relevance.
* Built a unified semantic search pipeline using FAISS Vector Database for cross-modal retrieval across text and image content.
* Generated image embeddings and integrated GPT-4 Vision for multimodal reasoning over charts, diagrams, and figures.
* Developed context-aware retrieval workflows capable of answering questions using both textual and visual evidence.
* Engineered metadata-driven indexing and page-level source attribution for enhanced document traceability.
* Enabled document summarization, visual content analysis, and multimodal question answering across enterprise documents.

**Key Skills:** Multimodal RAG, CLIP Embeddings, FAISS, Vector Search, GPT-4 Vision, LangChain, PyTorch, PDF Processing, Semantic Search, Prompt Engineering.

## Agentic AI Trip Planner (Multi-Agent System)

**Technologies:** Python, LangGraph, LangChain, FastAPI, Streamlit, Tavily Search, OpenAI/Groq LLMs, REST APIs

* Designed and implemented a multi-agent travel planning platform using LangGraph and Large Language Models.
* Developed specialized agents including Planner Agent, Research Agent, Budget Optimization Agent, and Itinerary Generation Agent.
* Built agent orchestration workflows with state management, conditional routing, and tool-calling capabilities.
* Integrated real-time web search tools to gather destination insights, tourist attractions, weather information, and travel recommendations.
* Automated itinerary generation based on traveler preferences, budget constraints, trip duration, and location-specific requirements.
* Implemented memory-aware agent collaboration to share context and improve decision-making across multiple planning stages.
* Developed API-driven services and interactive user interfaces for personalized travel planning experiences.
* Applied prompt engineering and structured output generation to improve itinerary quality, accuracy, and consistency.

**Key Skills:** Agentic AI, LangGraph, Multi-Agent Systems, Tool Calling, Workflow Orchestration, LLM Applications, FastAPI, Prompt Engineering, State Management, Travel Recommendation Systems.
